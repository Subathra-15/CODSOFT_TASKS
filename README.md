## 📌 Task Descriptions

### Task 1 — Movie Genre Classification
Predicts the genre of a movie based on its plot summary using NLP techniques and machine learning classifiers.

**Tech:** TF-IDF, Naive Bayes / Logistic Regression

---

### Task 2 — Credit Card Fraud Detection
Detects fraudulent credit card transactions from a highly imbalanced dataset using classification models.

**Tech:** Random Forest, SMOTE, Scikit-learn

---

### Task 3 — Customer Churn Prediction
Predicts whether a customer will leave a service based on their usage patterns and demographics.

**Tech:** Logistic Regression, Random Forest, Gradient Boosting

---

### Task 4 — Spam SMS Detection
Classifies SMS messages as spam or legitimate (ham) using text preprocessing and ML classifiers.

**Tech:** TF-IDF, Naive Bayes, SVM

---

### Task 5 — Handwritten Text Generation
Implements a character-level LSTM RNN trained on the TinyShakespeare dataset to generate handwritten-like text with temperature-controlled sampling.

**Tech:** TensorFlow/Keras, LSTM, Character-level RNN
